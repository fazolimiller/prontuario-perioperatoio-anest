# prontuario-perioperatoio-anest

Sub-sistema web (HTML) de registro perioperatório de anestesia, integrado ao MV. Cobre a ficha anestésica gráfica, a descrição com máscaras, as evoluções, a RPA, as caixas da farmácia e o controle de psicotrópicos.
